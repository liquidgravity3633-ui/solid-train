# GRAVITY-POWER

**Crafted By Nihaal Menon**

A Windows desktop starter for local AI using Ollama, with a branded chat interface, saved conversations, and Word / PowerPoint export.

## Package status

The Windows ZIP package is supplied separately by the creator. It is **not yet attached to this GitHub repository**, so this page does not provide a working GitHub ZIP download.

## Run on Windows

1. Install Python 3.11 or newer.
2. Install and start [Ollama](https://ollama.com/).
3. Extract the project ZIP, then double-click `START-GRAVITY-POWER.bat`.
4. If no local models are listed, use **Get starter model** in the app.
5. To build a standalone Windows executable on Windows, double-click `BUILD-EXE.bat`.

## Important

- GRAVITY-POWER is an application, not a newly trained foundation model.
- Ollama and its model weights are separate and are not bundled in the project ZIP.
- The EXE build script must be run on Windows; no prebuilt EXE is included here.
- This independent starter is not affiliated with Qoder.
