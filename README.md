# GRAVITY-POWER

**Crafted By Nihaal Menon**

A Windows desktop starter for running local AI through Ollama, with a branded chat interface, saved conversations, and editable Word and PowerPoint exports.

## Download

Download **[GRAVITY-POWER-Windows-Starter.zip](https://github.com/liquidgravity3633-ui/solid-train/raw/refs/heads/main/GRAVITY-POWER-Windows-Starter.zip)** and extract it on your Windows PC.

## Run

1. Install Python 3.11 or newer.
2. Install and start [Ollama](https://ollama.com/).
3. Extract the ZIP, then double-click `START-GRAVITY-POWER.bat`.
4. If no local models are listed, use **Get starter model** in the app.
5. To build a standalone Windows executable on Windows, double-click `BUILD-EXE.bat`.

## Important

- GRAVITY-POWER is an application, not a newly trained foundation model.
- Ollama and its model weights are separate and are not bundled in the ZIP.
- The EXE build script must be run on Windows; this repository does not claim a prebuilt EXE is included.
- This project is an independent GRAVITY-POWER starter and is not affiliated with Qoder.

## Project contents

The ZIP contains the Python desktop app, setup and launch scripts, Windows EXE build script, icon and logo assets, requirements, a GitHub Actions Windows build workflow, and tests.
